# Learning Model

## Pedagogical Position

Olingo is built around production-first practice for adult Italian learners. Recognition matters, but the highest-value behaviour is producing accurate sentences quickly enough for conversation.

Research anchors:

- Retrieval practice strengthens learning better than repeated study alone.
- Distributed practice and spaced repetition improve retention.
- Task-based and action-oriented learning make language practice meaningful.
- Formulaic sequences reduce pausing and support fluency because useful chunks can be retrieved as units.
- Adult learners benefit from clear goals, autonomy, varied tasks, and reflection on progress.

## The Daily Loop

The default daily session is 15 minutes:

1. Warm start, 1 minute: two easy wins from mastered phrases.
2. Due repairs, 4 minutes: mistakes scheduled by spaced repetition.
3. Sentence Forge, 5 minutes: typed construction and transformation.
4. Scene Quest, 4 minutes: photoreal roleplay with button-driven choices.
5. Debrief, 1 minute: fluency stats, one grammar note, next unlock.

The app chooses the session mix. The learner can override, but the default should reduce decision fatigue.

## Practice Types

### Chunk Retrieval

Goal: instantly recall useful phrase frames.

Examples:

- "Secondo me..."
- "Mi sembra che..."
- "Vorrei parlare di..."
- "Hai visto che...?"
- "Non sono sicuro, ma..."

These should be scheduled like SRS cards, but tested through production rather than recognition.

### Sentence Forge

Goal: build full Italian sentences from British English prompts.

Modes:

- Word tiles for new structures.
- Typed answer with hints for active structures.
- Timed typed answer for practised structures.
- Free production in scene quests.

### Transform Drill

Goal: make grammar flexible under light time pressure.

Example chain:

- "I want a coffee."
- "We wanted two coffees."
- "Could you bring us two coffees?"
- "I would have liked another coffee, but it was late."

Track transformations by:

- Person.
- Number.
- Tense.
- Mood or politeness.
- Direct/indirect object.
- Word order.
- Register.

### Mistake Repair

Goal: convert each mistake into future improvement.

Every wrong answer should create or update a mistake item:

- Original prompt.
- Learner answer.
- Corrected answer.
- Error tags.
- Explanation, short and optional.
- Repair drill variants.
- Next due date.

The learner should see mistakes as useful material, not failure.

### Scene Quest

Goal: practise purposeful communication inside a realistic situation.

Each scene should include:

- A photoreal background.
- One or more NPCs.
- A short social objective.
- Button choices for intent, tone, or action.
- Typed Italian response input.
- Feedback and next step.

Example objective: "At the cafe, explain that you read a headline about Milan and ask what your friend thinks."

## Spaced Repetition Model

V1 can evolve the existing scheduler from word cards to production items.

Schedulable item types:

- Phrase chunk.
- Sentence frame.
- Transformation pattern.
- Mistake repair.
- Scene objective.
- Grammar contrast.

Suggested outcomes:

- Again: incorrect or blank.
- Hard: correct after hints or slow.
- Good: correct with acceptable speed.
- Easy: fluent and accurate.

The old binary correct/wrong is too blunt for fluency work. Keep simple UI buttons, but record richer internal outcomes.

## Mistake Taxonomy

Initial tags:

- Article.
- Gender agreement.
- Number agreement.
- Verb conjugation.
- Tense choice.
- Auxiliary choice.
- Preposition.
- Pronoun or clitic.
- Word order.
- Missing word.
- False friend.
- Register or politeness.
- Idiomatic phrasing.
- Spelling/accent.

Each tag should have a small repair template library.

## Fluency Stats

Measure progress with:

- Response time: prompt shown to submitted answer.
- First-pass accuracy: accepted without correction.
- Repair success: mistake later answered correctly.
- Hint dependence: hints used per session.
- Chunk mastery: phrase frames produced correctly across intervals.
- Sentence length comfort: typical accurate sentence length.
- Scene confidence: completed objectives by context.

Avoid claiming pronunciation fluency until speech input is implemented.

## Feedback Style

Feedback should be:

- Immediate.
- Brief.
- Specific.
- Encouraging without being vague.
- Focused on one or two fixable things.

Example:

Corrected Italian:
"Secondo me il film era interessante, ma un po' lento."

Note:
"Use 'era' for a description in the past. 'Interessante' does not change for gender."

Repair:
"Now say: The book was interesting, but too long."
